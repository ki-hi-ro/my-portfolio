# Freelance Work Log

## 概要

成果物・技術ブログ・職務経歴を一元管理するポートフォリオサービスです。

---

## データ構造

### 制作物（Works）

|項目|説明|
|---|---|
|タイトル|成果物名|
|説明|概要説明|
|技術タグ|使用技術|
|GitHub|ソースコード|
|公開URL|デモサイト|
|画像|サムネイル|

### 技術ブログ（Articles）

|項目|説明|
|---|---|
|記事タイトル|記事名|
|URL|記事URL|
|技術タグ|関連技術|
|概要|記事要約|

### 職務経歴（Career）

|項目|説明|
|---|---|
|会社・案件|担当案件|
|期間|参画期間|
|担当内容|業務内容|
|使用技術|利用技術|
|成果|実績・改善内容|
